Font files for the text styles. Declared in `src/styles/fonts.css`; the weights each family offers in the sidebar are listed in `FONT_WEIGHTS` in `src/variables/schema.ts`.

| Family | Weights used | Files |
|---|---|---|
| Inter | 100–900 | `Inter/Inter-VariableFont_opsz,wght.ttf` |
| Geist Mono | 100–900 | `Geist_Mono/GeistMono-VariableFont_wght.ttf` |
| Ballet | 400 | `Ballet/Ballet-Regular-VariableFont_opsz.ttf` |
| Bricolage Grotesque | 700, 800 | `BircolageGrotesque/BricolageGrotesque-Bold.ttf`, `-ExtraBold.ttf` |
| Charis SIL | 400, 700 | `Charis_SIL/CharisSIL-Regular.ttf`, `-Bold.ttf` |
| Instrument Serif | 400 | `Instrument_Serif/InstrumentSerif-Regular.ttf` |
| Luckiest Guy | 400 | `Luckiest_Guy/LuckiestGuy-Regular.ttf` |

Italic and static files in the folders are not used (the text style has no italic option).
